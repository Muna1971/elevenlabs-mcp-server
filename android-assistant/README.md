# مُنى — مساعد رقمي ذكي لأندرويد (Muna Digital Assistant)

تطبيق أندرويد native يعمل كـ **مساعد رقمي افتراضي** (يظهر في إعدادات "تطبيق
المساعد الرقمي الافتراضي" ويُفتح بإيماءة المساعد). يجمع بين:

- **العقل:** Claude (Anthropic Messages API, `claude-opus-4-8`) للتفكير والرد.
- **الصوت:** ElevenLabs Text-to-Speech لنطق الردود.
- **الاستماع:** محرّك التعرّف على الكلام المدمج في أندرويد (يدعم العربية).
- **التفاعل:** صوتي ونصي معًا في واجهة محادثة واحدة.

## الميزات
- يظهر في قائمة "المساعد الرقمي الافتراضي" عبر `android.intent.action.ASSIST`.
- محادثة نصية + زر ميكروفون للتحدّث.
- شخصية قابلة للتخصيص (الاسم + التعليمات) من شاشة الإعدادات.
- تخزين مفاتيح الـ API محليًا ومُشفّرًا على الجهاز (`EncryptedSharedPreferences`).

## الإعداد قبل الاستخدام
افتح **الإعدادات** داخل التطبيق وأدخِل:
1. **مفتاح Anthropic** (من `console.anthropic.com`) — مطلوب للذكاء.
2. **مفتاح ElevenLabs** + **معرّف الصوت** — اختياري، لتفعيل الصوت.
3. عدّل **اسم وشخصية** المساعد كما تريد.

ثم: الإعدادات ← التطبيقات الافتراضية ← **تطبيق المساعد الرقمي** ← اختر "مُنى".

## البناء (Build)
يتطلب Android SDK (platform-34, build-tools 34) وJDK 17+.

```bash
cd android-assistant
echo "sdk.dir=/path/to/Android/sdk" > local.properties
./gradlew assembleDebug
# الناتج: app/build/outputs/apk/debug/app-debug.apk
```

## ملاحظات أمنية
- مفاتيح الـ API تُستخدم مباشرة من التطبيق إلى Anthropic/ElevenLabs وتبقى على الجهاز.
- هذا تطبيق شخصي؛ لا تشارك الـ APK موقّعًا بمفاتيحك مع الآخرين.

## البنية
| الملف | الدور |
|------|------|
| `MainActivity.kt` | واجهة المحادثة، الصوت، الاستماع، إيماءة المساعد |
| `ClaudeClient.kt` | استدعاء Claude (العقل) |
| `ElevenLabsClient.kt` | تحويل النص إلى صوت |
| `Prefs.kt` | تخزين المفاتيح والشخصية بشكل مُشفّر |
| `SettingsActivity.kt` | شاشة الإعدادات |
